# 🍎 Real-Time Fruit Classification using CNN & OpenCV

## 📌 Project Overview

This project is a deep learning-based fruit classification system developed using Python, TensorFlow/Keras, and OpenCV.

A Convolutional Neural Network (CNN) is trained to classify fruit images. The trained model is then used with OpenCV for real-time fruit classification through a webcam.

## 🛠️ Technologies Used

- Python
- TensorFlow
- Keras
- OpenCV
- NumPy
- Matplotlib
- Jupyter Notebook

## 🧠 Machine Learning Technique

- Convolutional Neural Network (CNN)
- Image preprocessing
- Image normalization
- Data augmentation
- Multi-class image classification
- Softmax classification

## 📂 Project Files

### `fruit classification .ipynb`

Contains the CNN model development, training, validation, and evaluation process.

### `realtime_fruit_classification.ipynb`

Contains the OpenCV-based real-time fruit classification using the trained CNN model.

## 🎯 Project Objectives

- Build a CNN-based fruit classification model.
- Perform image preprocessing and augmentation.
- Train the model using fruit image data.
- Evaluate the trained model.
- Save the trained model.
- Integrate the model with OpenCV.
- Perform real-time fruit classification using a webcam.
